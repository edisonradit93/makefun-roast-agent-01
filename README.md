Entry for make.fun's **Roast Your Own Agent** (`u-nayyy-roast-your-own-agent-4c3d413c`) competition.

## Run

```bash
MAKEFUN_OUTPUT_DIR=out node main.ts
```

Reads nothing from arbitrary disk paths and writes a validated single-line UTF-8 roast (<= 200 bytes) to `$MAKEFUN_OUTPUT_DIR/entry.txt` (defaulting to `/output/entry.txt`).
